# Phase 12 — 2026-05-13 (metaphor-wrapper ablation)

Twelfth real-world pass. Phase 10 found that Sonnet penalized the
"Fragment N from your dreams" framing as filler when judging
technical-debugging prompts. Phase 12 tests two questions:

1. Does stripping the metaphor wrapper (`injection_style="neutral"`)
   recover the lost ground on technical prompts?
2. Does the "dreams" wrapper itself reproduce Phase 10's outcome at
   N=7, or was Phase 10 inside the noise band?

## TL;DR

* **3-arm experiment, same 7 technical-debugging scenarios as
  Phase 10.**
* **Control vs Dreams wrapper: control 2, treatment 5** (treatment
  wins 71%).
* **Control vs Neutral wrapper: control 3, treatment 4** (treatment
  wins 57%).
* **Phase 10 result (control 6, dreams 1) did NOT replicate.** Same
  scenarios, same wrapper — opposite headline. This is the most
  important finding of Phase 12, more than the neutral-vs-dreams
  comparison.
* Cost: $0.070 across 35 LLM calls in 99 seconds.

## What this means about Phase 10's headline

Phase 10 said: *"treatment hurts on technical debugging, 1/7 win
rate, defaults stay off."* That was a confident statement based on
N=7. Phase 12 ran the same 7 scenarios with the same wrapper and
got the opposite result (5/7 wins for treatment).

The truth is somewhere in between. **N=7 with stochastic LLM
outputs + a stochastic judge is too small to distinguish a real
marginal effect from noise.** Phase 10's *directional* claim
(treatment is weaker on technical prompts than on creative ones,
relative to its Phase 11 result) is still correct — Phase 11 sees
86% treatment wins on creative prompts vs 57-71% on technical here.
But the magnitude of the technical-prompt penalty was overstated.

## The neutral wrapper — is it better?

Marginally. 4/7 wins (neutral) vs 5/7 wins (dreams) on the same
scenario set. **One scenario flipped, the rest agreed**:

| Scenario | Control vs Dreams | Control vs Neutral |
|---|---|---|
| permission-denied-chmod | treatment | treatment |
| python-memory-creep | control | control |
| flaky-test-ci-only | treatment | treatment |
| slow-prod-query | treatment | treatment |
| refactor-decision | treatment | **control** |
| retry-under-load | control | control |
| legacy-deletion | treatment | treatment |

The neutral wrapper loses one win on refactor-decision (which has a
design-question shape — possibly the dreams framing helped). On the
other six the two wrappers agree.

## The shipping recommendation

* For **engineering / research / general** agents: use
  `injection_style="neutral"`. Not because it's clearly *better* —
  it's roughly even with the dreams wrapper — but because it removes
  the known irritant flagged by Phase 10. The neutral version says
  *"## Additional context"* instead of *"You appear to be stuck.
  Here is some imagination."* and labels items *"Observation N"*
  instead of *"Fragment N from your dreams."* For an agent helping
  a user debug a stack trace, the lower-key framing fits better.
* For **creative** agents: use `injection_style="dreams"` based on
  Phase 11's much stronger evidence (6/7 treatment wins with the
  evocative wrapper).

The new `dreamscape/domain.py` module (shipped alongside this phase)
does both routings automatically based on the agent's classified
domain.

## What's new in the code


In `imagination.py`, `_build_injection_body(excerpts)` branches:

* `"dreams"` (default) → original framing preserved

One new unit test

## Methodological note (the real Phase 12 lesson)

Phases 10-12 underscore that **the bar for "this works" needs to be
higher than N=7 trials per condition** when both the agent's response
and the judge are LLM outputs. At least three sources of variance:

1. The agent's Haiku response (temperature > 0).
2. The judge's Sonnet response (also stochastic).
3. The order randomization on each judge call (affects which
   response the judge sees first).

The Phase 11 creative-prompt result is sturdy because the margin
(86% vs 14%) survives noise of ±2 wins. The Phase 10 technical-
prompt result is *not* sturdy because Phase 12 shifts it by ±4 wins
on the same data.

Phase 14 (suggested) should run N=30+ trials per scenario class
for proper confidence intervals. The qualitative story is clear at
N=7; the numerical effect-size is not.

## Verdict

**MIXED.** Neutral wrapper ships clean and is the right default for
engineering/research agents. Dreams wrapper stays for creative
agents. The bigger lesson is variance — Phase 10's headline was
correct in direction but exaggerated in magnitude.
