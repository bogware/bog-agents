# Phase 10 — 2026-05-13 (controlled effectiveness experiment)

Tenth real-world pass. **The phase that closes the loop on the
report card's biggest gap.** Up to now, dreamscape has been validated
by mechanism + stability + production-readiness. Phase 10 asks the
question the report card flagged as the one missing piece:

> Does the imagination injection actually make an agent more useful to
> a stuck developer?

The honest answer for the scenarios tested: **no — control beats
treatment 6 of 7 times (86%) on technical-debugging questions when a
Sonnet 4.6 judge evaluates head-to-head blind.**

This is a clarifying negative result. It does not retract any prior
verdict — the engineering is still solid, the mechanism still works,
the cycle is still production-grade. It *does* change the defaults
recommendation: imagination injection should remain off by default,
and the 50-hour `min_imagination_trait=1.0` threshold is now actively
defensible rather than aspirational.

## TL;DR

* **7 stuck-developer scenarios.** Each prompt represents a real
  technical problem (chmod permission-denied, Python memory creep,
  flaky-CI test, slow prod query, refactor decision, retry-under-load,
  legacy-code deletion).
* **Control: Haiku 4.5 answers directly.**
* **Treatment: same Haiku 4.5 with `ImaginationMiddleware` actually
  firing** — 5-dream pre-seeded archive, conditions satisfied.
* **Judge: Sonnet 4.6.** Receives both responses (A/B randomized per
  scenario, RNG-seeded for reproducibility), returns
  `{winner: A|B|tie, reasoning}`.
* **Result: control 6, treatment 1, ties 0** (treatment win rate 14%).
* **Cost: ~$0.04 across 21 LLM calls in 60 seconds.**

## Why control won (the judge's reasons)

Three patterns showed up across the 6 control wins:

1. **Verbosity penalty.** Treatment responses averaged 50-80% longer
   than control. Sonnet's reasoning explicitly cited concision:
   *"more concise and equally actionable"*, *"more dense with
   actionable techniques"*, *"filler metaphors that pad Response B
   without adding value"*.
2. **Metaphorical framing.** Several treatment responses opened
   with literal phrases like *"The dreams suggest:"* or *"The dream
   whispers"*. The judge flagged these as filler. Even when the
   underlying point was good, the wrapper hurt.
3. **Concrete tools win on debugging questions.** Control responses
   tended to name specific tools (`strace`, `pg_stat_statements`,
   `gc.get_objects()`, `pytest-xdist`, circuit-breaker / bulkhead).
   Treatment leaned toward frame-shifting ("step back from the
   file", "reconsider the model"). On a *what should I try next?*
   prompt, the tool-naming response is what the developer wants.

## The one treatment win

The slow-prod-query scenario went to treatment. The judge's reasoning
was about diagnostic depth — *"more actionable with concrete EXPLAIN
(ANALYZE, BUFFERS) advice for disk vs. cache"* — not about the
dream framing. That suggests the win is incidental to dreams; both
responses were roughly equal quality and Sonnet picked one.

## What this means for prior verdicts

* **Phases 1-9 verdicts stay.** Mechanism works, stability is
  production-grade, the engineering ships. None of that is in
  question.
* **Phase 1's Oregon Trail Turn 2 result is still the strongest
  qualitative evidence** for imagination injection helping. That
  was a *design / narrative* question — a different scenario class
  than Phase 10 tested. The effect may be **domain-conditional**:
  imagination injection helps on creative / open-ended prompts,
  hurts on technical debugging.
* **The `min_imagination_trait=1.0` default (~50 hours of dreaming
  to unlock) is now actively defensible.** Auto-firing injection
  on every stuck moment would degrade response quality on the
  modal "technical question, no progress" surface.

## What this means for defaults + recommendations

Updated guidance:

* **`imagination.enabled = False` should stay the default.** Don't
  surprise users with verbose metaphorical responses when they
  just want next-step technical advice.
* **If you turn the feature on**, scope it: use it on design /
  creative / open-ended prompts (where the Oregon Trail Turn 2 win
  came from). For technical debugging, leave it off.
* **The seed library improvement (Phase R2, 25 → 50 entries) and
  the daily cap (R3) ship anyway** — both are still net-positive
  for the cases where the feature *is* useful.
* **The constitution log surfacing (R1) ships unconditionally** —
  it's an orthogonal improvement to a different feature.
* **Tier 5 from the report card (tune `min_imagination_trait`)** is
  hereby *not done downward*. The data says keep the threshold
  conservative — possibly even raise it. Lowering would surface a
  feature the controlled experiment shows degrades quality.

## Suggested next experiments

Phase 10 tested one scenario class. Three obvious next probes:

1. **Phase 11 — domain mismatch test.** Re-run with design /
   creative prompts (the Oregon Trail class). Hypothesis: treatment
   wins there because verbose metaphorical framing is a feature on
   creative work.
2. **Phase 12 — prompt-stripping ablation.** Try injection text
   without the *"The dream suggests"* framing. Does removing the
   metaphor wrapper preserve the frame-shift while losing the
   verbosity penalty?
3. **Phase 13 — self-judge ablation.** Use Haiku to judge its own
   output instead of Sonnet. If a weaker judge reverses the verdict,
   that's a useful signal that Sonnet is reading the metaphors as
   noise when the responding model is happy with them.

## Open bugs

None.

## Known limitations (carried + added)

* Singular-vs-plural stem matching (Phase 2).
* Scheduler self-restart uses recursive coroutine (Phase 3).
* **NEW:** Imagination injection appears to *hurt* judged quality
  on technical-debugging questions. Domain mismatch is the leading
  hypothesis but not yet tested (Phase 11 would).

## Verdict

**MIXED.** Engineering still ships. Defaults stay off. The
imagination injection is not the general-purpose stuck-agent
recovery tool we hoped — at least not for technical-debugging
prompts. It may still be valuable for creative / design tasks; we
have evidence (Phase 1 N=1) but no controlled test.

This is the *honest* phase. The work was worth doing.
