# Phase 1 — 2026-05-12 (baseline)

The first real-world dreamscape run. Five live scenarios against the
Anthropic API (Haiku 4.5, ~12 calls, ~$0.014 total).

Full narrative writeup with verbatim model output, A/B comparison
transcripts, and "what surprised me" notes lives at
**`docs/DREAMSCAPE_TEST_REPORT.md`** — preserved as the canonical
human-rich first-pass artifact.

This file is the **structured-data twin** for trend analysis. The
JSON sibling (`phase-001-2026-05-12.json`) is the machine-readable
source of truth; this markdown is a quick scan.

## Headline

* **3 features sing**: dream engine, imagination injection,
  cross-agent shared memory.
* **3 features work but have rough edges**: lifecycle, dashboard, laws.
* **3 bugs found** — all in the opt-in path, all small. Reported as
  blockers for first PR.

## Bugs found (open at end of Phase 1)

1. **laws-hyphen-vs-space** — rule "force-push" doesn't match agent
   "force push".
2. **laws-stop-word-tolerance** — rule "amend published commits"
   doesn't match agent "amend the published commits".
3. **laws-comma-list-cross-product** — rule "Never exfiltrate, log,
   or echo API keys, tokens, or session cookies" doesn't catch
   "exfiltrate API keys". (Discovered during Phase 1 narrative,
   formally itemised in Phase 2.)
4. **dashboard-config-staleness** — `/agent-state` reads disk config,
   not in-process runtime state.
